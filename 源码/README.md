# 应试词汇覆盖统计（Anki 插件）

看清你牌组里到底覆盖了多少应试词汇。按牌组 / 标签 / 笔记类型 / 学习状态任意组合筛选，
分别统计**英语轴**（四级、六级、四六级并集、考研、雅思、托福、GRE）和**日语轴**
（N5–N1、JLPT 并集）的「总词数 / 已覆盖 / 覆盖率 / 未覆盖」，并显示覆盖来源占比。

## 语言分成两条独立轴线

英语轴和日语轴**不混算**。用英语词表的词去比日语 JLPT 的词，比例没有意义，
所以顶部是「英语应试 / 日语 JLPT / 全部」三档；选「全部」时两块分开显示，
各自的分母和覆盖率互不干扰。

`工具\构建词库索引.py` 也复用同一套归一规则，保证构建期和运行期对得上。

## 统计口径（先说清楚，免得数字打架）

- 统计单位默认**唯一词（按词元去重）**，笔记数 / 卡片数作为辅助数字；
  顶部下拉可以切换总览的范围规模与状态分布，但**覆盖页永远是唯一词口径**，
  因为覆盖率的分母是词表总词数。
- 学习状态按 Anki 的 `type` / `queue` 判定，暂停与埋葬单独一档；
  同一个词有多张卡、状态不同时归到进度最高的那个（复习 > 学习 > 未学习）。
- 来源维度默认牌组，取最具体的那一级子牌组；同一个词出现在多个来源时只算一次。
  来源页可切「牌组 / 标签 / 笔记类型」三种维度：牌组维度一个词只算一次，标签与笔记类型
  维度按出现次数各算一次（没标签的归「（无标签）」，占比各自加总 100%），
  标签维度排除插件自家 `应试::…` 标签。
- 一个词同属多个词表（四级＋六级、日语跨级词）时，每个词表各自都算已覆盖，
  并集只算一次。
- 筛选口径：分类之间取交集、分类之内可选并集。
- 分母标了来源与版本，界面里不出现「官方覆盖率」这种说法。

## 变形识别

英文：原词命中 → ECDICT `exchange` 词元 → `lemma.en.txt` → 显式去变形规则表 → 保守后缀兜底。
规则表整理自 fushi 应用的 `transforms/en.json` 共 16 组，覆盖复数（`s/es/ies/ves`）、
所有格、过去式（`ed/ied/双写`）、`-ing`（`ying→ie`）、第三人称、比较级 / 最高级、
`-ly/-ily→y`、`-ly→le`、`-able/-ible`、`-ful/-less`、`-ness`、`-ment`、`-tion`，
以及 `un-/in-/im-/dis-` 前缀。短语与连字符归一：`make-up↔makeup`、`per cent↔percent`、
`health care↔healthcare`、`post-war↔postwar`；词表里含空格 / 连字符的词（如 `co-operative`）
原样命中。英美拼写（colour/color、fulfil/fulfill）双向认。歧义（`does` 既像 `do` 又像 `doe`）按
「原词自带标签 → 候选带考试标签 → 词频」消歧，分不出来就**按未覆盖处理，不猜**。

日语：全角半角、片假名↔平假名、忽略 `・` 与空格，**长音符只在比较时按需忽略**
（`ビル` / `ビール` 这类仍然分开），汉字表记与假名读音双向精确匹配，
`お/ご/御` 接头词剥掉后再试，`〜する` 复合动词剥尾后再试；
另外用 fushi 的 `transforms/ja.json` 活用规则做**受控**还原——只采纳能命中词表的候选，
不做激进词干还原。一个假名对应多个不同词条时按未覆盖处理。

## 明细页的「原因」只有两态

界面上每个词只有**已覆盖 / 未覆盖**两种显示，没有「待确认」之类的中间档。歧义词一律算未覆盖。
内部还留着三类细分（真未覆盖 / 识别失败 / 待确认），但它只做两件事：决定哪些词不该重复制卡、
供自动化测试断言用。v0.3 的验收指标就是**识别失败 = 0**——凡是词表里有、你卡里也有的词，
都必须认出来，不许落进「未覆盖」。

> 小提示：未覆盖清单的条数不一定刚好等于覆盖页「总词数 − 已覆盖」。因为有些词在词表里
> 占了两行（`analyse` / `analyze`、`stairs` / `stair` 这类同词不同词条），而你的卡片只会算成一个词元。
> 两个数都是对的，只是口径不同。

## 明细页：多词表筛选与打标签

明细页「只看命中词表 / 只看某词表未覆盖」两档左侧是可勾选的词表列表：勾几个按几个筛，
一个都不勾＝不按词表过滤；命中档还能选「任一命中（并集）」或「全部命中（交集）」。判词逻辑
是纯函数（`analysis.filter_words_by_codes`），界面和测试共用同一套。

命中档勾了具体词表后，可给当前列出的命中笔记批量打上 `应试::四级 / 六级 / 考研 / 雅思 /
托福 / GRE / JLPT-N5…N1` 标签（合并码「四六级并集 / JLPT 并集」不生成标签），也有移除按钮。
两处都先弹确认框写明影响条数。

## 「应试词命中率」是什么

自动识别字段时会抽该字段 60 条非空内容，看多少条能命中 ECDICT / JLPT 应试词表——这就是
设置页上的「应试词命中率」。它只是「像不像应试词」的参考分，**不进入任何统计数字**；
高分但非取词字段的列（词性、句子类型等）靠「字段名一票否决」挡掉，整句/长文本列会被标成
「像例句/长文本，已跳过」。

## 只读承诺

统计时不改字段、不改排期。唯一的写操作是明细页「打标签 / 移除这些标签」按钮：
只在你亲自点击 + 确认后，才给命中的笔记加/去 `应试::…` 标签（走 Anki 后端
`bulk_add/bulk_remove`，`Ctrl+Z` 可撤）。真实 Anki 的隔离探针里有一条回归：
跑完整套流程（含打标签再撤销）后，所有卡片的 `did / type / queue / due / ivl / reps`
快照、以及笔记字段与标签快照，都必须与跑之前完全一致。

## 补漏卡与内置素材库

明细页的「一键生成补漏牌组…」只处理当前筛选结果里的**真未覆盖**词，新建独立牌组
（`应试补漏::四级` …）并自带精简笔记类型「应试补漏卡」，字段为
`单词 / 假名·音标 / 释义 / 例句 / 例句译 / 音频 / 考试标签 / 来源`。
每张卡必定带**单词、音标或假名、释义、例句、音频**；素材不全的词不会进队列，会写进报告。
新牌组的新卡上限默认设成 0（让你先检查），整组 `Ctrl+Z` 可撤。
音频包还没解压到本机时，点「一键生成补漏牌组…」不会落卡，而是先问你「要现在下载素材库吗」——
避免生成一批只有文字、没声音的卡片（判定见 `builder.split_by_audio`）。提示里也会告诉你
可以改用设置页的「从本地 zip 文件安装…」，那条路不联网。

素材全部来自插件内置索引，不再现场扫描本机词典、也不联网取词：

- 英文：wordforge 中文释义 + ECDICT 中文 / 英英释义，音标来自词典 IPA，例句来自词书 / 本机词典 / Tatoeba。
- 日语：eggrolls 的中日释义与例句，公开表补的部分用明镜日汉双解；读音和例句来自各公开表。
- 音频：英文 OALD10 真人英美音，日语 NHK16 / 新明解 / 大辞泉 / Forvo / JPod101 等真人音。

文本素材（释义、例句）随插件打包；音频包约 200 MB，放在 GitHub Release。
新设备在设置页点一次「一键构建素材库」＝下载 + 校验 sha256 + 解压到
`%APPDATA%\Anki2\<配置>\exam_vocab_stats\media\`，之后全离线。下载支持断点续传；
如果音频包已经在手边，或者下载不稳，直接用设置页的「从本地 zip 文件安装…」选那份
`exam_materials_audio.zip`，后台算 sha256 后解压到同一个目录，**全程不联网**。
内置索引里的 `src` 字段保留了每个词条的来源标记。

## 联网说明

除下面两处外全程离线，两者都**不发送任何卡片内容**、也不采集：

1. 更新检查（默认开着，可在设置页关掉）：每天最多一次，只读 GitHub 上的 `version.txt` 和新版分发包。
2. 一键构建素材库（默认不跑，要你自己点）：只在本地缺音频包时才下载一次。

「从本地 zip 文件安装…」不联网，只是把本机那份音频包解压进用户配置目录。

## 钩子与界面稳定性

Anki 各版本的 `gui_hooks` 回调参数个数并不一致（26.09 的 `browser_menus_did_init`
只传 `browser` 一个参数）。`hook_guard.py` 在注册前用 `inspect.signature(...).bind()`
试一遍：对不上就记日志跳过，绝不因为签名变化把界面搞崩。只拦签名不匹配这一种错，
回调内部真正的异常照旧抛出。卡片浏览器菜单栏里有一个顶级菜单「应试词汇」。
