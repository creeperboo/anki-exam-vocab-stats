# 应试词汇覆盖统计 · 插件配置

这份文件是给 Anki 的「插件配置」界面看的，用来说明下面每个键是什么意思。
多数设置建议直接在插件界面右上角的「设置」页里改（那里改完会立刻重新统计）；
手改这里的 JSON 后要**重启 Anki**才生效。

- **field_map**：**每个笔记类型从哪个字段取词**，键是笔记类型的内部编号，值是配置。
  第一次打开插件时会自动扫一遍所有笔记类型、按「像不像单词字段」打分填好，
  默认全空 `{}`。一般不用手改，在「设置」页勾选更直观。
  每一项包含：
  `enabled`（是否参与统计）、`fields`（按顺序取词的字段名列表）、
  `fallback_fields`（兜底字段）、`reading_field`（日语假名字段，用来把假名对应回汉字表记）、
  `language`（`en` 英语 / `ja` 日语 / `none` 不统计）、
  `allow_sentence`（是否允许从例句里分词，**默认 false**，打开后容易把例句里的常见词算进来）。
  例外的两个默认值：英语词库 `English-CEFR` 的 `vocabularyWord` 默认勾选；
  `Lapis` 的 `Expression` 虽然也是英文词，但它是**英文释义型牌库**，默认不勾选（会污染两条轴）。
- **enabled_exams**：英语轴要显示哪些词表，可选
  `cet4` 四级、`cet6` 六级、`ky` 考研、`ielts` 雅思、`toefl` 托福、`gre` GRE。
  另外 `zk` 中考、`gk` 高考两张词库在索引里也有，勾上就会出现。
  默认六级全勾。**「四六级并集」不是这里的开关**，它总是跟着 `cet4`/`cet6` 一起显示。
- **enabled_levels**：日语轴要显示哪些等级，可选 `n5` `n4` `n3` `n2` `n1`。
  **「JLPT 并集」不是这里的开关**，它总是跟着这几个等级一起显示。
- **language**：打开窗口时默认停在哪个轴：`en` 英语应试 / `ja` 日语 JLPT / `all` 全部。
  选「全部」时英文块和日文块分开显示，**不会把上万个英文词和上万个日语词混成一个比例**。
- **count_unit**：顶部「统计单位」下拉的初始值：
  `unique_lemma` 唯一词（按词元去重，**默认**）、`note` 笔记数、`card` 卡片数。
  覆盖率的分母和分子永远按唯一词算，这个开关只影响总览页的辅助数字。
- **source_dimension**：来源页按什么维度拆分，默认 `deck`（牌组）。可选 `deck` 牌组 /
  `tag` 标签 / `notetype` 笔记类型。牌组维度一个词只算一次、归到最具体的子牌组；
  标签和笔记类型维度一个词按出现次数各算一次，没标签的归「（无标签）」，占比各自加总 100%；
  标签维度会排除插件自己打的 `应试::…` 标签。切维度会立刻重新统计（缓存键里带了它）。
- **allow_duplicate_source**：`false`（默认）＝同一个词即使出现在多个牌组里，
  也只归给**主来源**算一次；`true`＝每个来源各算一次（来源页的词数会大于去重后的词数）。
- **state_rule**：同一个词有多张卡、状态不一样时怎么归类，默认 `highest_progress`
  （复习 > 学习 > 未学习）。
- **lemma_merge**：默认 `true`，**按词元组合并标签**——认识 `child` 就算认识 `children`。
  关掉后改成「只认原词自己带的标签」，不做任何词形还原。
- **show_uncovered**：明细页是否默认提供「只看未覆盖」这一档，默认 `true`。
  明细页只有三档：**全部词条 / 只看已覆盖 / 只看未覆盖**（v0.3 起不再有「待确认」中间档）。
  未覆盖档里的词表是可勾选的多选列表（零个＝不按词表过滤），「只看已覆盖」时可选
  「任一命中 / 全部命中」，并能在确认后给命中的笔记批量打 `应试::…` 标签。
  界面上每个词只有**已覆盖 / 未覆盖**两种显示；歧义（一个假名对应多个词条）一律按未覆盖算，
  内部的三类细分（真未覆盖 / 识别失败 / 待确认）只用来决定「哪些词不该重复制卡」和测试断言，
  不会出现在界面上。「一键生成补漏牌组」做「真未覆盖」+「待确认」两类（界面都算未覆盖），
  只有「识别失败」不做——它只是匹配没认出，做卡会重复已有内容。
- **builder_defaults**：「一键生成补漏牌组」的默认值——`limit` 单次上限（默认 500）、
  `new_per_day` 新牌组的新卡上限（默认 0，先不让 Anki 自动出新卡）、
  `add_tags` 是否同时打 `应试::…` 标签（默认 true）。
  制卡素材（单词 / 音标·假名 / 释义 / 例句 / 音频）**全部读插件内置的素材索引**，
  不再现场扫描本机词典；素材缺项的词不会进补漏队列，会写进报告里。
  音频包没解压到本机时也**不会落卡**：先弹窗问要不要现在下载素材库，
  避免生成「只有文字、没声音」的半截卡片（判定见 `builder.split_by_audio`）。
- **materials_source / materials_sha256 / materials_installed_at**：内置音频素材包的状态。
  文本素材（释义、例句）随插件打包，音频包（约 200 MB）放在 GitHub Release，
  在「设置」页点「一键构建素材库」下载、校验 sha256 后解压到
  `%APPDATA%\Anki2\<配置>\exam_vocab_stats\media\`（下载支持断点续传）。这三个键只是记录
  装的是哪一版、什么时候装的。旁边的「从本地 zip 文件安装…」走同一个解压入口，不联网。
- **materials_zip**：上次用「从本地 zip 文件安装…」时选的文件路径（默认空）。
  下次打开文件对话框时优先跳到这个目录，其次 `桌面\应试插件\工具\素材构建`，其次桌面。
- **auto_cleanup**：默认 `true`。打开 Anki 后约 12 秒静默检查一次补漏牌组，把「已经被
  任何一张具体词表认出、而且从未进入学习」的补漏卡删掉（已开始学习 / 复习的永久保留）；
  整批合成一个撤销步骤，`Ctrl+Z` 可撤。不弹窗，只把日志写到用户配置目录的
  `cleanup_log.json`（留最近 20 次）。关掉就完全不检查。
  设置页「素材库与一键补漏制卡」区有同名勾选框和「立即检查并清理」按钮。
- **cleanup_keep_empty_decks**：默认 `true`＝补漏牌组被清空后**保留**牌组本身；
  改成 `false` 则顺带把清空的补漏牌组删掉。
- **cache_enabled**：默认 `true`。统计结果缓存在**用户配置目录**的
  `exam_vocab_stats\summary-<签名>.json`（不往插件目录里写东西），
  签名包含集合修改时间、笔记/卡片最大修改时间、字段映射、词库版本；
  只改一张卡时只有对应签名的那份缓存失效。关掉后每次都重算。
- **update_check**：默认 `true`。开着时插件启动 8 秒后悄悄查一次有没有新版本，
  **每天最多一次**，只在真的有新版时才弹窗问一句；关掉就完全不联网。
  检查更新时只请求两个地址——仓库里的 `version.txt`（版本号）和新版分发包
  `.ankiaddon`，都用 https，**不发送任何卡片内容**，也不采集。
  另一处可选联网是设置页的「一键构建素材库」（下载约 200 MB 的音频包 + 校验 sha256），
  只在你自己点的时候才跑一次。除此之外词表和文本素材都随插件打包，全离线可用。
- **scope**：上次用的统计范围，跟着界面走，一般不用手改：
  `deck_ids`（牌组编号，空＝全部）、`include_subdecks`（是否含子牌组）、
  `tags_include`（要包含的标签）、`tags_exclude`（要排除的标签）、
  `tag_mode`（`any` 任一命中 / `all` 全部命中）、
  `notetype_ids`（限定笔记类型，空＝不限）、
  `states`（`new` 未学习 / `learn` 学习中 / `review` 复习中 / `suspended` 暂停埋葬）、
  `search`（Anki 搜索式，用来跟卡片浏览器的筛选结果对齐）。

筛选口径是「**分类之间取交集、分类之内可选并集**」：
牌组、标签、笔记类型、状态四类条件同时生效（交集）；
同一类里勾多个值，默认任一命中（并集），标签可以用 `tag_mode` 切成「全部命中」。
