应试词汇覆盖统计 · 操作指南
================================

这个插件回答四个问题：

  1. 我这个牌组 / 这批标签里，到底有多少应试词汇？
  2. 其中未学习 / 学习中 / 复习中 / 暂停埋葬各占多少？
  3. 每张词表（四级、六级、考研、雅思、托福、GRE、JLPT N5–N1）覆盖了多少，还差多少？
  4. 覆盖到的那些词来自哪里、各占多少？

除「检查更新」和「一键构建素材库」这两件事外，插件全部离线运行，
统计时只读你的集合，不改字段、不动排期。
写操作只有两个，都在明细页，都要你亲自点击、并在确认框里点「确定」才执行：
「打标签 / 移除这些标签」给命中的笔记加上 应试::… 前缀的标签；
「一键生成补漏牌组…」给没学过的词新建 应试补漏::… 牌组和卡片。
两个都能用 Ctrl+Z 整组撤销，都不碰你现有卡片的字段和排期。


一、在哪里打开
---------------

四种入口，用哪个都行：

  · 主界面菜单「工具 → 应试词汇覆盖统计…」，统计范围默认是全部；
  · 牌组列表里右键某个牌组 →「统计这个牌组的应试词汇…」；
  · 卡片浏览器里菜单 →「统计当前筛选结果的应试词汇…」（会带上下面的搜索式）；
  · 打开主窗口后点右上角的「选择范围…」，手动勾选牌组、标签、笔记类型、状态。

第一次打开会先扫一遍你的笔记类型，自动判断「从哪个字段取词」。

「选择范围」里选牌组时：

  · 整行点一下就能勾上（不用非点那个小方框）；勾父牌组会连带它的子牌组；
  · 上面一排有「全选 / 全不选 / 只选父牌组」三个按钮；
  · 底部实时写「已选 N 个牌组（含子牌组共 M 个）」，一眼能看出到底选进去多少。


二、默认的字段识别结果
-----------------------

插件按「这个字段像不像单词字段」打分来推荐，并给出语言判断：

  · English-CEFR           → vocabularyWord        （英语，默认勾选）
  · eggrolls-JLPT10k-v3.5  → VocabKanji            （日语，假名兜底 VocabFurigana）
  · Kaishi 1.5k zh-CH      → Word                  （日语，假名兜底 Word Reading）
  · Lapis                  → Expression 是英文词，默认【不勾选】（想统计到设置页打个勾）
  · おにぎり文法            → 语法点，不是词汇，默认排除
  · 普通问答 / 法学 / 选择题 → 默认排除

自动结果只是起点。设置页里每一行都能改：

  启用 / 笔记类型 / 取词字段 / 兜底或假名字段 / 语言 / 例句分词 / 说明

「例句分词」默认关着。打开后会把整句拆成一个个词一起统计，
例句里的常见词会把覆盖率抬高，一般不建议开。


三、变形识别（同一个词的不同写法怎么合到一起）
-----------------------------------------------

英语轴（四级到 GRE 共用一套）：

  ① 先看原词在不在词表里；
  ② 再查 ECDICT 的词元字段（children → child、ran → run、better → good）；
  ③ 再查 lemma.en.txt 词元表；
  ④ 最后才用显式的去变形规则表兜底。这套表整理了 fushi 应用 transforms/en.json 的
     16 组规则，覆盖：复数（-s / -es / -ies / -ves）、所有格、过去式（-ed / -ied / 双写）、
     -ing（ying → ie）、第三人称、比较级 / 最高级、-ly / -ily → y、-ly → le、
     -able / -ible、-ful / -less、-ness、-ment、-tion，以及 un- / in- / im- / dis- 前缀。

  英美拼写也一起认：colour → color、organise → organize、fulfil → fulfill。
  短语和连字符会归一：make-up ↔ makeup、per cent ↔ percent、health care ↔ healthcare、
  post-war ↔ postwar；词表里本来就带空格或连字符的词（比如 co-operative、t-shirt）原样命中。
  一个词形同时能被两个词元认领时（例如 does），按「原词自己带的标签优先 → 候选里带考试
  标签的优先 → 词频」来消歧；分不出来就算未覆盖，不猜。

  默认「合并词元组标签」＝认识 child 就算认识 children。设置页里可以关掉，
  关掉后只认原词自己带的标签，不做任何词形还原。

日语轴（保守，不做词干还原）：

  · 全角半角统一、片假名 ↔ 平假名统一、忽略 ・ 和空格；
  · 长音符「ー」只在比较时按需忽略，ビル（大楼）和 ビール（啤酒）仍然分开；
  · 汉字表记和假名读音双向精确匹配（食べる ↔ たべる）；
  · 「お / ご / 御」接头词剥掉后再试一遍；
  · 「〜する」复合动词只在剥掉 する / します / した 后能命中词表时才采纳；
  · 另外用 fushi 应用 transforms/ja.json 的活用规则做受控还原——只采纳能命中词表的候选，
    不做激进词干还原。

  同一个假名对应好几个不同词条（跨等级）时按未覆盖处理，不猜。


四、六个页签分别看什么
-----------------------

总览
  顶部选语言（英语应试 / 日语 JLPT / 全部）和统计单位（唯一词 / 笔记 / 卡片）。
  左边是学习状态环图，右边是各词表的命中数、占范围内词数的比例、词表总词数。

覆盖
  每个词表一行：词表总词数 / 已覆盖 / 覆盖率 / 未覆盖 ＋ 进度条。
  英语轴六行（四级、六级、考研、雅思、托福、GRE）＋「四六级并集」；
  日语轴五行（N5–N1）＋「JLPT 并集」。选「全部」时英文块和日文块分开显示。

  · 一个词同时属于四级和六级时，两张词表各自都算已覆盖；并集只算一次。
  · 覆盖率 = 已覆盖 ÷ 词表总词数。**这一页永远按唯一词算**，不随统计单位变化。
  · 分母来自公开词库：英语用 wordforge 六本词书 ∪ ECDICT（MIT）、
    日语用 eggrolls JLPT10k ∪ tanos ∪ OpenJLPT，
    不是考试机构官方大纲数字，适合自检和补漏，不适合对外宣称「官方覆盖率」。

来源
  选一张词表，看覆盖到的词都来自哪些来源，各占多少（堆叠条 ＋ 表格）。
  顶部「来源维度」下拉可在 牌组 / 标签 / 笔记类型 之间切：

    · 牌组：一个词只算一次，归到最具体的子牌组（六级词汇::真题 优先于 六级词汇）；
    · 标签：一个词有几个标签就在几行各记一次，没标签的归「（无标签）」，
      插件自己打的「应试::…」标签会自动排除，免得打完标签污染来源图；
    · 笔记类型：同理，按笔记类型名各记一次。

  切维度会立刻重算；来回切换不会把上面的词表选择冲掉。

明细
  逐词表格：词元 / 原始写法 / 语言 / 命中词表 / 状态 / 卡片 / 来源牌组 / 原因 / 备注。
  三档筛选：全部词条、只看已覆盖（命中词表）、只看未覆盖（用来拿补漏清单）。

  已覆盖档和未覆盖档左边有一个可勾选的词表列表：勾几个就按几个筛，一个都不勾＝不按词表
  过滤。已覆盖档还能选「任一命中（并集）」或「全部命中（交集）」。

  「原因」列只有两种显示：已覆盖 / 未覆盖。歧义（一个假名或词形对应好几个词条）一律算未覆盖。
  界面背后还留着三类细分（真未覆盖 / 识别失败 / 待确认），但它只做两件事：决定哪些词不该
  重复做成补漏卡、供自动化测试断言用，不会显示在界面上。v0.3 的验收要求是「识别失败 = 0」，
  也就是凡是词表里有、你卡里也有的词，都必须认出来。

  已覆盖档勾了具体词表后，右下角可以：
    · 「打标签」——给当前列出的命中笔记批量加上 应试::四级 / 六级 / 考研 / 雅思 / 托福 /
      GRE / JLPT-N5…N1 标签（并集那一行不打标签）；
    · 「移除这些标签」——把同样的标签批量去掉。
  两处都会先弹确认框写明影响多少条笔记，走 Anki 后端的加/去标签，Ctrl+Z 可撤销。

  未覆盖档勾了具体词表后，右下角还多一个：
    · 「一键生成补漏牌组…」——只给「真未覆盖」的词建卡（其实有卡只是没认出来的词会跳过，不重复制卡）。
      它会新建 应试补漏::四级 这类牌组，配一个自带笔记类型「应试补漏卡」，字段是
      单词 / 假名·音标 / 释义 / 例句 / 例句译 / 音频 / 考试标签 / 来源。
      素材全部读插件**内置**的素材索引（释义、例句随插件打包；音频来自内置音频包），
      不联网、不改你的集合，音频写进 Anki 媒体库；
      每张卡必定带单词、音标或假名、释义、例句、音频；素材不全的词不进队列，会写进报告。
      生成前会弹确认框报清楚「多少条笔记、多少个音频、哪些牌组」；
      新牌组的新卡上限先设成 0（你检查满意后在牌组选项里自己放开）；
      一次 Ctrl+Z 就能把整组撤掉。生成上限、新卡上限、要不要顺手打标签，在设置页调。

  双击一行 → 在卡片浏览器里打开对应的笔记。左下角「复制词表」把当前列表复制走，
  右上角「导出 CSV」导出全量（明细页超过 3000 行只显示前 3000，导出的拿全量）。

设置
  上面是每个笔记类型的取词字段配置；下面是词表开关、词元合并、缓存开关，
  以及「重新识别字段 / 清除缓存 / 保存设置并重新统计」三个按钮。
  最下面一行写着当前词库索引的来源、构建时间和许可证。
  再往下还有一块：
    · 「素材库与一键补漏制卡」——显示内置文本素材（英语多少个词、日语多少个词）和音频包状态；
      「一键构建素材库（下载音频包）」＝下载约 200 MB 的内置音频包、校验 sha256 后解压到
      %APPDATA%\Anki2\<配置>\exam_vocab_stats\media\，之后制卡全离线；
      以及制卡参数：单次最多生成多少张、新牌组的新卡上限、制卡时要不要顺手打 应试:: 标签。


五、统计口径（数字怎么算的）
-----------------------------

  · 统计单位默认「唯一词」：按词元去重，children 和 child 算一个词；
    笔记数、卡片数在旁边作为辅助数字。
  · 学习状态按 Anki 的 type / queue 判定，暂停和埋葬单独列一档。
  · 同一个词有多张卡、状态不一样时，归到进度最高的那个（复习 > 学习 > 未学习）。
  · 来源维度默认「牌组」，取最具体的那一级子牌组。
  · 筛选按「分类之间取交集、分类之内可选并集」：
    牌组、标签、笔记类型、状态四类条件同时生效；
    同一类里勾多个值默认任一命中（并集），标签可以切成「全部命中」（交集）。

  界面里所有分母都标了数据来源和版本，没有「官方」两个字。


六、性能与缓存
---------------

  · 统计结果缓存在**用户配置目录**的 exam_vocab_stats 文件夹里，
    不会往插件目录里写东西。
  · 缓存签名 = 集合修改时间 ＋ 笔记/卡片最大修改时间 ＋ 字段映射版本 ＋ 词库版本，
    所以改一张卡只会让相关的那份缓存失效，其余照旧命中。
  · 设置页的「清除缓存」会把它们全删掉。
  · 两万条笔记的量级，一般一两秒内出结果；范围越大、开的笔记类型越多就越慢，
    状态栏里会显示实际用时和是否用了缓存。


七、常见问题
-------------

问：为什么某个词明明学过，却算在「未覆盖」里？
答：界面只会写「已覆盖」或「未覆盖」。先确认这个笔记类型的「取词字段」有没有配对，
    没配对的话整列都读不到，去设置页改。
    如果确实是词表里有、你牌组里也有，插件却算成未覆盖，那就是匹配疏漏——
    v0.3 把「识别失败 = 0」当成硬指标（构建期、探针都断言），一般不该出现；
    真出现了请把完整词形和它所在的笔记类型发我。
    剩下能落到「未覆盖」的，就是词表里有、你牌组里确实没有的词，
    可以直接用「一键生成补漏牌组…」补上。

问：为什么 Lapis 默认不统计？
答：它的取词字段是英文词，但整张卡是日语学习牌库，直接算会把英语轴的命中率抬高。
    想统计就在设置页把这一行勾上，立刻生效。

问：会不会改我的卡片？
答：统计本身只读，不改字段、不改排期、不上传任何内容。写操作只有两个，都在明细页，
    都要你点、并在确认框里点「确定」：
      · 打标签 / 移除这些标签——给命中的笔记加/去 应试::… 标签；
      · 一键生成补漏牌组——新建 应试补漏::… 牌组和「应试补漏卡」笔记，
        不会碰你现有的模板、牌组和卡片。
    两个都能 Ctrl+Z 整组撤销。真实 Anki 的隔离探针里专门做了「跑完整套流程（含打标签、
    制卡再撤销）后卡片快照、笔记字段/标签快照完全一致」的回归。
    制卡只读插件内置的素材索引与音频包，不联网、不改你现有的收藏。

问：会不会联网？
答：只有两件事会联网，都不发送任何卡片内容、也不采集：
      · 「检查更新」——默认开着，可在设置页关掉，每天最多查一次。只从 GitHub 读两个地址：
        仓库里的 version.txt 和新版分发包 .ankiaddon，都用 https。
      · 「一键构建素材库」——默认不跑，要你自己点；只在本地缺音频包时才下载一次。
    词表索引、释义、例句都是随插件打包好的，除此之外全部离线可用。
    想彻底不联网，到设置页把「启动时自动检查更新」的勾去掉即可。

问：设置页那个百分数（应试词命中率）是什么意思？
答：它是自动识别字段时的参考分：抽这个字段 60 条非空内容，看有多少条能命中 ECDICT / JLPT
    应试词表。它只回答「这一列像不像应试词」，不进入任何统计数字。所以有些命中率很高、
    但不是取词字段的列（词性、句子类型等），插件会靠「字段名一票否决」挡掉；如果一列
    大多是整句、长文本，会在说明列写成「像例句/长文本，已跳过」，而不是笼统地说命中率低。

问：生成的补漏卡会不会有的有音频 / 释义、有的没有？
答：不会。素材全部来自插件内置索引，每张卡必定带单词、音标或假名、释义、例句、音频；
    四项里缺任何一项的词根本不会进补漏队列，会写进生成报告。例句的中文翻译允许留空
    （英文 48.8%、日语 97.5% 有译文），其余四项都是 100%。
    第一次用之前要先在设置页点一次「一键构建素材库」把音频包下下来（约 200 MB），
    下完之后制卡全离线、秒级完成。
    要是还没装音频包就点了「一键生成补漏牌组…」，插件会直接问你要不要现在去下载，
    并先不落任何卡片——不会生成一批只有文字、没声音的半截卡。
